# 📻 MBC 표준FM LIVE (Australia Edition)

호주에서 모바일(특히 **아이폰/안드로이드**)로 한국 MBC 표준FM을 끊김 없이 청취할 수 있도록 최적화된 고품질 웹 애플리케이션(PWA)입니다.

---

## 🌟 주요 특징 (v2.1.0 스크린세이버/주머니 무중단 & 음영지역 무인 자동 복구 가디언)

1. **아이폰(iOS) 스크린세이버/화면 꺼짐/주머니 무중단 재생 (Apple Native Engine)**:
   - 아이폰 Safari에서 화면을 끄거나 주머니에 넣었을 때 자바스크립트가 동결되며 버퍼가 끊기던 현상을 원천 해결.
   - iOS 환경에서는 애플 OS 커널 레벨의 **AVPlayer/CoreMedia 네이티브 HLS 엔진**을 최우선 구동하여, 화면이 꺼지고 기기가 잠겨도 OS가 백그라운드 세그먼트 다운로드를 24시간 끊김 없이 유지합니다.
   - `navigator.audioSession.type = 'playback'`(iOS 16.4+) 선언으로 하드웨어 무음 스위치나 화면 잠금 시에도 소리가 꺼지지 않습니다.

2. **음영지역(터널, 엘리베이터, 지하 주차장) 무인 자동 재개 (Zero-Touch Auto-Resume)**:
   - 1분 이상 장시간 통신이 두절되어 버퍼가 고갈되더라도, 플레이어가 오류로 종료되지 않고 **스마트 대기 모드(`📶 음영지역 통과 중 — 신호 복구 시 즉시 자동 재생`)**로 자동 전환됩니다.
   - 백그라운드 핑으로 기지국 신호 복구를 실시간 감지하여, 터널이나 엘리베이터를 빠져나와 신호가 잡히는 순간 **사용자가 폰을 꺼내지 않아도 0.5초 만에 자동으로 방송 재생이 재개(Auto-Resume)**됩니다.

3. **안드로이드/PC 전용 타임시프트 딥 윈도우 확장기 (129초 버퍼 엔진)**:
   - 안드로이드 크롬 및 PC에서는 HLS.js와 딥 버퍼 엔진이 결합되어, 과거 38개 세그먼트를 복원해 65~90초 대용량 사전 오디오 버퍼를 메모리에 충전하여 모바일 통신 지연을 방어합니다.

4. **공식 MBC 3중 멀티 CDN 무중단 페일오버**:
   - `minisw.imbc.com` ↔ `minisa.imbc.com` ↔ `minisp.imbc.com`
   - 동일한 보안 토큰을 공유하는 MBC 공식 3대 GSCDN 클러스터를 커스텀 로더에 통합하여, 호주 국제망 지연 발생 시 세그먼트 단위로 즉시 우회 다운로드.

5. **실시간 공식 MBC 편성표 연동**:
   - `miniapi.imbc.com`의 공식 편성 데이터를 실시간(JSONP)으로 동기화하여, 현재 방송 프로그램 제목, 방송 시간, 다음 방송, 공식 고화질 앨범 아트(포스터)를 실시간 반영합니다.

6. **미려하고 모던한 미니멀 디자인 (Anti-AI Aesthetic)**:
   - Braun / Teenage Engineering / Apple Music 감성의 딥 오프블랙 테크웨어 디자인 적용.
   - 현재 방송 프로그램 커버와 반응하는 동적 앰비언트 글로우(Ambient Blur) 배경 및 정밀 버퍼 모니터 게이지 탑재.

7. **잠금화면, 에어팟, 스마트워치, 차량 블루투스(CarPlay/Android Auto) 연동 (MediaSession API)**:
   - 잠금화면과 제어센터, 차량 내비 화면에 현재 방송명과 앨범 커버가 표시되며, 리모컨 버튼으로 재생/일시정지가 완벽 연동됩니다.

## 📱 아이폰(iPhone) 제대로 설치하는 방법 (PWA 홈 화면 추가)

아이폰에서 브라우저 주소창이나 하단 툴바 없이, **앱스토어에서 받은 진짜 앱처럼 전체화면으로 사용**하려면 아래 순서대로 설치하세요:

1. **아이폰 Safari(사파리)로 접속**:
   - 크롬이나 네이버, 카카오톡 인앱 브라우저가 아닌 **Safari 앱**으로 해당 주소(`https://[유저아이디].github.io/my-radio`)에 접속합니다.
2. **[공유] 버튼 탭**:
   - 사파리 화면 하단 중앙에 있는 **공유 아이콘** (네모 상자 위로 화살표가 뻗은 모양 `⎋`)을 누릅니다.
3. **[홈 화면에 추가] 선택**:
   - 메뉴를 아래로 살짝 내린 뒤 **[홈 화면에 추가]** (Add to Home Screen)를 선택합니다.
4. **우측 상단 [추가] 탭**:
   - 이름('MBC 라디오')을 확인하고 우측 상단의 **[추가]**를 누릅니다.
5. **홈 화면에서 앱 실행**:
   - 홈 화면에 생긴 **MBC 라디오 앱 아이콘**을 눌러 실행합니다.
   - 사파리 주소창/버튼이 모두 사라진 **완전한 전체화면 전용 오디오 앱**으로 구동되며, 화면을 끄거나 다른 앱(카카오톡, 내비 등)을 써도 백그라운드에서 끊김 없이 재생됩니다.

## 🛠️ 기술 사양

- **Stack**: Pure HTML5, CSS3, JavaScript (ES6+ 단일 파일 `index.html`).
- **Data APIs**: 
  - `sminiplay.imbc.com`: 실시간 보안 HLS 스트림 토큰 발급 (JSONP)
  - `miniapi.imbc.com`: 실시간 공식 편성표 및 앨범 아트 메타데이터 (JSONP)
- **Audio Engine**: HLS.js + iOS Safari Native HLS Time-Shifted Buffering.
- **Hosting**: GitHub Pages.
