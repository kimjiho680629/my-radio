# 📻 MBC 표준FM LIVE (Australia Edition)

호주에서 모바일(특히 **아이폰/안드로이드**)로 한국 MBC 표준FM을 끊김 없이 청취할 수 있도록 최적화된 고품질 웹 애플리케이션(PWA)입니다.

---

## 🌟 주요 특징 (v2.0.0 호주 모바일 딥 버퍼 & 멀티 CDN 엔진 탑재)

1. **타임시프트 딥 윈도우 확장기 (Time-Shift Deep Buffer Expander)**:
   - MBC 공식 플레이리스트의 15초(세그먼트 5개) 노출 한계를 극복.
   - 서버에 살아있는 과거 38개 세그먼트(약 114초)를 실시간 복원·결합하여 총 129초 윈도우로 확장, 재생 즉시 65~90초 대용량 오디오 버퍼를 메모리에 고속 충전.
   - 호주 모바일 음영 지역(터널, 엘리베이터, 기지국 핸드오버)에서 통신이 1분 이상 끊겨도 무중단 재생 유지.

2. **공식 MBC 3중 멀티 CDN 무중단 페일오버**:
   - `minisw.imbc.com` ↔ `minisa.imbc.com` ↔ `minisp.imbc.com`
   - 동일한 보안 토큰을 공유하는 MBC 공식 3대 GSCDN 클러스터를 커스텀 로더에 통합하여, 호주 국제망 지연 발생 시 세그먼트 단위로 즉시 우회 다운로드.

3. **iPhone iOS WebKit `ManagedMediaSource` 방어 & 백그라운드 워커**:
   - iOS Safari가 셀룰러 환경에서 10~15초 만에 버퍼링을 멈추던(`endstreaming` -> `pauseBuffering`) 현상을 원천 방어하여 목표 버퍼까지 지속 다운로드.
   - 유휴 대기 시 `onstalled` 이벤트로 재생 헤드를 강제 점프시키던 버그를 제거하고 미세 갭 브릿징 적용.
   - 화면 잠금 시 메인 스레드 타이머 쓰로틀링에 대비해 Web Worker 하드웨어 타이머와 `audio.ontimeupdate` 클럭으로 백그라운드 로더 구동.

4. **실시간 공식 MBC 편성표 연동**:
   - `miniapi.imbc.com`의 공식 편성 데이터를 실시간(JSONP)으로 동기화합니다.
   - 현재 한국 시간(KST)에 맞춰 **실제 방송 중인 프로그램 제목**, **방송 시간**, **다음 방송 예고**, **공식 고화질 앨범 아트(포스터)**가 자동으로 표시됩니다.
   - 시간이 바뀌면 1분 단위로 자동 감지하여 프로그램 정보가 자동으로 전환됩니다.

5. **미려하고 모던한 미니멀 디자인 (Anti-AI Aesthetic)**:
   - 전형적인 AI 느낌의 네온 그라데이션을 배제하고, 클래식 오디오 기기(Braun / Apple Music) 감성의 딥 오프블랙 테크웨어 디자인을 적용했습니다.
   - 현재 방송 프로그램 커버와 반응하는 **동적 앰비언트 글로우(Ambient Blur)** 배경.
   - 슬릭한 정밀 **버퍼 리저브 게이지(Buffer Reserve Monitor)** 및 실시간 네트워크 메트릭 탑재.

6. **원클릭 즉각 복구 (Smart Play Trigger)**:
   - 방송이 멈췄거나 버퍼링 중일 때 재생 버튼을 누르면 즉시 최신 스트림 세션을 재발급받아 강제 재생합니다.

7. **아이폰 잠금화면 & 에어팟 연동 (MediaSession API)**:
   - 아이폰 잠금화면과 제어센터, 에어팟 리모컨에 현재 프로그램명과 앨범 아트가 표시되며, 화면이 꺼져도 백그라운드 재생이 유지됩니다.

## 📱 아이폰(iPhone) 제대로 설치하는 방법 (PWA 홈 화면 추가)

아이폰에서 브라우저 주소창이나 하단 툴바 없이, **앱스토어에서 받은 진짜 앱처럼 전체화면으로 사용**하려면 아래 순서대로 설치하세요:

1. **아이폰 Safari(사파리)로 접속**:
   - 크롬이나 네이버, 카카오톡 인앱 브라우저가 아닌 **Safari 앱**으로 해당 주소(`https://[유저아이디].github.io/my-radio`)에 접속합니다.
2. **[공유] 버튼 탭**:
   - 사파리 화면 하단 중앙에 있는 **공유 아이콘** (네모 상자 위로 화살표가 뻗은 모양 `⎋`)을 누릅니다.
3. **[홈 화면에 추가] 선택**:
   - 메뉴를 아래로 살짝 내린 뒤 **[홈 화면에 추가]** (Add to Home Screen)를 선택합니다.
4. **우측 상단 [추가] 탭**:
   - 이름('MBC 라디오')을 확인하고 우측 상단의 **[추가]**를 누릅니다.
5. **홈 화면에서 앱 실행**:
   - 홈 화면에 생긴 **MBC 라디오 앱 아이콘**을 눌러 실행합니다.
   - 사파리 주소창/버튼이 모두 사라진 **완전한 전체화면 전용 오디오 앱**으로 구동되며, 화면을 끄거나 다른 앱(카카오톡, 내비 등)을 써도 백그라운드에서 끊김 없이 재생됩니다.

## 🛠️ 기술 사양

- **Stack**: Pure HTML5, CSS3, JavaScript (ES6+ 단일 파일 `index.html`).
- **Data APIs**: 
  - `sminiplay.imbc.com`: 실시간 보안 HLS 스트림 토큰 발급 (JSONP)
  - `miniapi.imbc.com`: 실시간 공식 편성표 및 앨범 아트 메타데이터 (JSONP)
- **Audio Engine**: HLS.js + iOS Safari Native HLS Time-Shifted Buffering.
- **Hosting**: GitHub Pages.
